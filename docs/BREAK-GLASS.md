# Break-Glass Mode

Break-glass is a narrow exception to normal hierarchy. It is not a shortcut for convenience.

## Allowed cases

- critical production fix;
- security containment;
- worker fleet unavailable;
- blocking integration repair.

## Required audit fields

- actor;
- timestamp;
- reason;
- affected task/work package;
- exact scope;
- files modified;
- commands/actions performed;
- tests/evidence;
- post-action reviewer.

## Authority

Terra may perform narrowly scoped integration repair. Sol may intervene for critical architecture-level containment. Normal implementation should return to Luna as soon as the emergency condition ends.
