# Human Escalation

Human escalation exists for decisions that should not be guessed by the AI hierarchy.

## Triggers

- ambiguous product/business intent;
- destructive production action;
- credential/security decision requiring owner authority;
- multiple valid architecture options where preference matters;
- plan cannot satisfy mutually contradictory human requirements.

## Minimum decision record

A human gate should include:

- decision ID;
- concise problem statement;
- options;
- evidence/tradeoffs;
- recommended option, if any;
- consequence of no decision;
- blocking scope.

After a human decision, Sol records the decision and revises the plan if necessary before execution resumes.
